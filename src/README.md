# BenmoshOS
## Making an OS, but i know nothing about it
This is a project to learn how to make an operating system, and to have fun doing it. I will be using the following resources:
- [OSDev](https://wiki.osdev.org/Main_Page) - A great resource for learning how to make an operating system.
- [Bran's Kernel Development Tutorial](https://www.osdever.net/bkernel/) - A tutorial that will guide me through the process of making a simple operating system.

### how to build and run
To build the operating system, use the command `make` <br/>
to run (in linux) use the command `make run` <br/>
to remove the binary files use the command `make clean`
